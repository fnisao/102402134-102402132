# 拾光校园｜校园失物招领

基于上一轮结对作业的“拾光校园”原型实现的 PC 与手机自适应网页。可发布寻物和招领、浏览与搜索、查看详情及联系方式，并由发布者在找回或归还物品后更新状态。

## 运行

1. 下载本目录的全部文件，保持目录结构不变。
2. 用 **Google Chrome** 打开 `index.html`。无需服务器、安装依赖或联网。
3. 首页可浏览示例线索，也可按类型切换；点击卡片查看详情。
4. 点击“搜索”，输入物品名称、地点或外观特征，还可按类别与寻物／招领筛选。
5. 点击“发布”，选择寻物或招领，填写表单后提交；发布成功后进入“我的发布”。
6. 打开自己发布的信息，物品找回或归还后点击“标记为已找到／已归还”。状态完成后详情页隐藏联系方式。

### 给测试人员的一条完整路线

首页 → 发布寻物 → 填写“蓝色雨伞”等内容 → 发布成功 → 我的发布 → 打开详情 → 标记已找到 → 观察联系方式消失。随后进入搜索页输入“雨伞”，可在结果中看到刚才的记录和预置示例。

## 数据与边界

- 首次打开有四条**虚构演示数据**；演示联系方式也均为虚构值。
- 自己发布的数据保存在当前浏览器的 `localStorage` 中。关闭页面再打开仍可查看；清除网站数据或换电脑后不会同步。此版本没有服务器和账号系统，因此“我的发布”只识别当前浏览器创建的信息。
- 完成状态的信息仍可被搜索和查看，方便其他人知道线索已结束；其联系方式被隐藏。
- 复制联系方式会先尝试浏览器剪贴板接口；本地文件环境下若不可用，会尝试备用复制方式。两种方式都失败时会提示手动复制，详情页仍会显示可选择的文字。
- 若已有本地数据格式损坏，页面会显示演示信息并提示；下一次成功发布会覆盖异常数据。
- 浏览器若禁用本地存储，会提示数据可能无法在关闭页面后保留。

## 自动化测试

需安装 Node.js 18 或更新版本，仅用于运行测试；使用网页本身无需 Node.js。

在项目根目录执行：

```text
node --test tests/logic.test.js
```

测试使用 Node.js 内置 `node:test` 与 `node:assert`，无需安装第三方包。用例覆盖发布校验、搜索排序、组合筛选、空结果、本人权限、重复完成、联系方式隐藏、恶意文本转义、损坏数据与日期边界。

## 原型对应关系

本网页沿用上次“拾光校园”原型的青绿寻物、暖橙招领、卡片式线索和底部导航。完整流程为“发布 → 浏览或搜索 → 详情 → 联系 → 发布者更新状态”。[核心流程图](docs/flow.svg)。
